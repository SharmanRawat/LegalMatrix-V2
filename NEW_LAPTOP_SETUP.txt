--------------------------------------------------

  # Start server (keep running in its own terminal):
  ollama serve &
  # Pull both models (one-time, large downloads):
  ollama pull qwen2.5vl:7b     # ~5 GB, VLM oracle + rescue + legacy extraction
  ollama pull qwen2.5:3b       # ~2 GB, SLM field classifier
  ollama list                  # both must appear
  curl http://localhost:11434/api/tags   # must return JSON, not "connection refused"

  Notes:
  - Modelfile in repo root pins `FROM qwen2.5vl:7b` + num_ctx 8192. No custom
    `ollama create` needed for dev (compose builds it only for prod GPU server).
  - GPU not required on this laptop: 7B runs slow on CPU but the audit script
    caches oracle reads, so you pay the cost once. Daily tuning uses the 3B + CPU OCR.
  - If RAM < 16 GB, keep VLM_RESCUE_ENABLED=0 (default) and close the browser
    during full sweeps.

11. TROUBLESHOOTING
-------------------
  - `curl localhost:11434 → refused`: ollama serve not running; start it.
  - `ollama pull` slow/stuck: check disk + RAM; retry; models resume.
  - `rapidocr` import error: venv used wrong python — recreate with python3.12,
    reinstall both requirements files.
  - `cv2 / libGL` error: sudo apt install -y libgl1 libglib2.0-0 (section 2).
  - `npm install` fails: node -v must be 20+; delete frontend/node_modules + package-lock? No —
    never delete package-lock.json, just `npm cache clean --force` and retry.
  - frontend 500 / timeout on inspect: backend down or Ollama down; 600 s timeout is
    normal for first 7B call — wait, then check backend terminal logs ([OCR] lines).
  - `/mnt/e/... not found`: in WSL run `ls /mnt/e`; if empty, restart WSL
    (`wsl --shutdown` from Windows) and ensure E: drive connected.
  - `git push` asks for password: use your fine-grained token as password, or
    `gh auth login` again. Never put the token in `git remote -v` URL.
  - pytest failures after fresh clone: ensure LEGALMATRIX_DATA_DIR not pointing at a
    stale db; tests use temp dirs automatically — just run `./venv/bin/python -m pytest -q`.
